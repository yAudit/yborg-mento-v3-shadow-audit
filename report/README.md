# Cantina Mento V3 results

Cantina published the final competition results as a web report rather than a standalone PDF:

- [Official Mento V3 results](https://cantina.review/mentoc7a87d)
- [Cantina announcement](https://x.com/cantinasecurity/status/2016809297192374771)

The official results record **zero Highs and seven unique Mediums**. The local files in this directory provide an offline index suitable for tooling and evaluation:

- `accepted-findings.md` — human-readable answer key.
- `accepted-findings.json` — machine-readable answer key.

Finding descriptions remain linked to Cantina as the canonical source. The index preserves the contest finding IDs, exact titles, severities, repository attribution, and canonical URLs.
